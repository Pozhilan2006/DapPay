# Development setup

## Prerequisites

- Python 3.12+
- Node.js 20+
- Docker Desktop or Docker Engine
- PostgreSQL 16

## Local bootstrap

1. Copy backend env files.
2. Install Python dependencies.
3. Start PostgreSQL.
4. Run the backend with uvicorn.
5. Run the frontend with npm run dev.

## Quality gates

- Ruff or black for Python linting
- Pytest for backend tests
- TypeScript build validation for frontend
