# Architecture overview

This repository is intentionally scaffolded with modular ownership boundaries so multiple developers can work in parallel without collisions.

## Backend domains

- PayPal integration
- Payment/webhook ingestion
- Database and schema management
- Reconciliation engine
- Event lineage and graph analysis
- AI investigation workflows
- Resolution planning

## Frontend domains

- Dashboard overview
- Transaction lists and filters
- Reconciliation monitoring
- Investigation detail flows
- Lineage and graph visualizations
